# Weekday

Weekday is an ASP.NET Core application hosted at <https://weekday.azurewebsites.net>.

It can:

- show the weekday for a date;
- derive a site-specific password locally in the browser;
- demonstrate basic ASP.NET Core security controls.

## Password-generator security model

Version 2 replaces the original Stanford PwdHash prototype and is intentionally incompatible with
all passwords generated by the old implementation. Existing credentials must be migrated one site
at a time; never overwrite a working credential until the new password has been accepted and tested.

The new generator:

- uses the exact normalized hostname as its security boundary, preventing collisions between
  independently controlled hosts such as `weekday.azurewebsites.net` and
  `attacker.azurewebsites.net`;
- encodes the complete master password as UTF-8;
- derives 256 bits with PBKDF2-HMAC-SHA-256 and 600,000 iterations;
- returns a fixed 32-character password with guaranteed upper-case, lower-case, digit, and special
  characters;
- does not load third-party JavaScript or submit the master password to the server;
- clears the master-password field immediately after successful derivation.

The hosted page remains remotely changeable and therefore depends on the integrity of the server.
For higher-value credentials, clone or download the repository, disconnect from the network, and open
`tools/offline-password-generator/index.html` locally in a current browser.

## Security controls

The application enables:

- HTTPS redirection and one-year HSTS;
- secure, HTTP-only, SameSite cookies;
- a restrictive Content Security Policy;
- clickjacking, MIME-sniffing, referrer, and browser-permission protections;
- removal of IIS and ASP.NET disclosure headers where the hosting platform permits it.

The application has no external frontend runtime dependencies; the previous jQuery and Bootstrap
files were removed.

## Development

Requirements:

- .NET 10 SDK
- Node.js 22 or newer, used only to run dependency-free JavaScript tests

Run the checks with:

```sh
npm test
dotnet build src/WeekDayWebApplication/WeekDayWebApplication.sln --configuration Release
```
